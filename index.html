Written instructions

Edit any row and the chart updates as you type. Use K3, P2, YO, M1L, M1R, KFB, K2tog, SSK, K3tog, SK2P, S2KP, P2tog, SSP, Sl1, C4F, C4B, NS (no stitch), a color like K3 (B), or a repeat like [K2, P2] × 3. Rows are written as you work them, so on wrong-side rows a chart knit is written as P.
